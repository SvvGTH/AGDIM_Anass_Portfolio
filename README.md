# AGDIM_Anass_Portfolio

Portfolio d’Anass Agdim, élève ingénieur IA & Data à l’ESIEA Paris, en double diplôme avec le MSc AI for Business Transformation de SKEMA.

Site en ligne : https://svvgth.github.io/AGDIM_Anass_Portfolio/

## Contenu

- `index.html` : la page (HTML, CSS et JavaScript dans un seul fichier, sans dépendance).
- `404.html` : page affichée par GitHub Pages pour un lien cassé.
- `assets/cv/` : CV en PDF, en français et en anglais.
- `assets/fonts/` : police Archivo (licence SIL Open Font, voir `OFL.txt`), hébergée sur le site pour ne pas bloquer l’affichage.
- `assets/og.png` : image affichée quand le lien est partagé (LinkedIn, messageries).
- `robots.txt` et `sitemap.xml` : pour les moteurs de recherche.

## Mettre à jour

Modifier `index.html` puis pousser sur `main`. GitHub Pages republie le site en une à deux minutes.
